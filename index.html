TaskFlow

Gerenciador de tarefas em que cada usuário vê e altera só as próprias tarefas.

  • Python
  • FastAPI
  • SQLAlchemy
  • PostgreSQL
  • Alembic
  • Docker
  • JWT
  • pytest
  • API REST em FastAPI com 8 endpoints: cadastro, login, perfil e CRUD de tarefas.
  • Login com JWT que expira em 60 minutos e senhas guardadas com hash bcrypt.
  • Toda consulta de tarefa filtra pelo dono: editar ou apagar a tarefa de outro usuário devolve 404, e a exclusão tem teste automatizado.
  • SQLAlchemy com PostgreSQL 16, migrations com Alembic e Docker Compose subindo a API e o banco.
  • 8 testes com pytest, rodando em SQLite em memória por meio de dependency_overrides.

O projeto começou como uma CLI em Python com MySQL. A versão seguinte, em Flask e MySQL, tem três camadas (rotas, serviços e repositórios), proteção CSRF, limite de requisições e login por sessão. O front em React com TypeScript está em desenvolvimento.

  • Código da API no GitHub
  • Código da versão Flask no GitHub

Custos da Cozinha (app de pesagem)

Em uso na Dudu Bebidas.

Registra o peso de cada alimento que sai da cozinha e o que volta como sobra, para calcular o custo de produção do dia.

  • JavaScript
  • Vite
  • Firebase
  • Vitest
  • GitHub Actions
  • Python
  • pytest
  • Calcula peso líquido, custo de produção e percentual de sobra com decimal exato, sem ponto flutuante.
  • Cada saída guarda uma cópia da tara, do preço por quilo e da taxa do momento, então mudar o cadastro não altera relatórios antigos.
  • Gera o relatório do dia em PDF no próprio navegador.
  • Regras de segurança do Firestore testadas no emulador: só a conta do dono lê e grava.
  • O GitHub Actions roda os testes e só publica se todos passarem.

Autoria: escrevi as regras de cálculo e os 32 testes em Python (pytest). O app web foi desenvolvido com apoio de IA (Claude Code).

  • Código do app de pesagem no GitHub

CheckListsDudu

Em uso na Dudu Bebidas.

Checklist diário por setor, preenchido no celular, para o chefe conferir o que foi feito em cada turno.

  • JavaScript
  • Vite
  • Firebase
  • Vitest
  • GitHub Actions
  • Cinco setores, cada um com conta própria, que vê e preenche só o próprio checklist. Quatro deles têm turnos de almoço e noite, e a limpeza é diária.
  • Nos itens que pedem foto, o “Sim” só é aceito com a foto gravada junto. A imagem é reduzida no celular antes do envio.
  • Cada resposta guarda o nome de quem preencheu, e o painel do chefe mostra progresso, observações e fotos por data.
  • Limpeza automática: fotos são apagadas em 7 dias e respostas em 30.
  • Regras do Firestore testadas com Vitest nos emuladores do Firebase. O GitHub Actions só publica se os testes passarem.

Autoria: especifiquei, revisei e publiquei o sistema. O código foi desenvolvido com apoio de IA (Claude Code).

  • Código do CheckListsDudu no GitHub

Autocelesc

Baixa a 2ª via das faturas de energia da CELESC de cerca de 42 unidades de uma prefeitura, sem abrir o portal unidade por unidade.

  • Python
  • Playwright
  • python-dotenv
  • Faz login no portal com Playwright e percorre as unidades uma a uma, salvando cada PDF com nome único.
  • Espera o carregamento terminar e fecha o aviso que cobre a tela antes de clicar.
  • Unidade sem fatura em aberto é pulada sem interromper a execução. Se o download não vem, o bot salva uma captura de tela para depuração.
  • Pausa entre as ações e navega por dentro do site, sem recarregar a página, para reduzir o risco de bloqueio.
  • Se o portal bloquear o IP, a execução é retomada manualmente a partir da unidade em que parou.

Sistema de Automação Empresarial

API para cadastrar clientes, automações e as execuções delas (jobs), com acesso separado por perfil. É um projeto de aprendizado, sem usuários reais.

  • Node.js
  • TypeScript
  • Express
  • PostgreSQL
  • Docker
  • JWT
  • Código do Sistema de Automação no GitHub
  • Camadas separadas: Routes → Controllers → Services → Repositories.
  • Login com JWT e dois perfis, ADMIN e FUNCIONARIO. Rotas como cadastrar cliente ou excluir automação exigem ADMIN.
  • 16 endpoints para usuários, clientes, automações e jobs, com os status PENDENTE, PROCESSANDO, CONCLUIDO e ERRO.
  • PostgreSQL 16 em Docker Compose, migrations em SQL e queries parametrizadas com o driver pg.
  • Limitações: ainda não há worker (o status do job é atualizado pela API) nem testes automatizados, e o front foi feito com apoio de IA.

Outros sistemas feitos para a Dudu Bebidas

  • Controle de proteínas. Saída e retorno diário de carnes, custo do dia e relatório. TypeScript, React, Vite e Firestore, com as regras do Firestore testadas com Vitest. Regras, serviços e cálculos escritos por mim; interface com apoio de IA. Código do Controle de proteínas no GitHub
  • Cadastro de refeições por empresa. Lançamento diário de refeições, fotos das notas convertidas em PDF, PDF mensal e fechamento do mês. React, TypeScript e Firebase. Login, empresas e regras do Firestore escritos por mim; o restante com apoio de IA. Código do Cadastro de refeições no GitHub
