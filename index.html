01 Automação

Python · Playwright · Automação

AutoCelesc

Robô que baixa automaticamente as faturas de energia de dezenas de unidades, eliminando o trabalho manual de acessar o portal documento por documento. Faz login, navega entre as unidades e lida com o carregamento dinâmico das páginas.

Destaque técnico

Mecanismo de retomada que salva o progresso e continua de onde parou caso a conexão seja bloqueada, tratando unidades sem fatura sem interromper a execução.

02 Web app

Flask · Segurança · Blueprints

Task-Flow Web

Aplicação web de gerenciamento de tarefas com interface própria, construída em Flask. O foco está em segurança e boas práticas: senhas protegidas com hashing, prevenção contra SQL injection, proteção CSRF e controle de sessão.

Arquitetura

Organizada em módulos com Blueprints para manter o código limpo e escalável.

Task-Flow API
